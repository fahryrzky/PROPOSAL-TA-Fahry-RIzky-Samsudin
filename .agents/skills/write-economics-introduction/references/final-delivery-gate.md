# Silent Final Delivery Gate

Apply this checklist privately to the exact complete candidate. Never mention, quote, summarize, score, or narrate the gate. Repair silently. The next and only visible response is the clean requested deliverable.

1. **Inspect the first and last visible characters.** A draft or rewrite starts immediately with English manuscript prose. It contains no `Now I...`, `Let me...`, process assurance, title, heading, quotation, code fence, horizontal rule, or separator. After the last English manuscript paragraph, either stop or add only one or two short, unlabelled plain sentences in the user's language for a material nonblocking risk, normally no more than about 50 English words or an equivalent compact Chinese length. The note summarizes missing evidence categories collectively; it never quotes, numbers, or rebuts rejected claims one by one. No assessment heading, list, or `omitted above` commentary is permitted.
2. **Scan every semantic join.** Check hooks, background generalizations, compound nouns, comparisons, evaluative modifiers, `because`, `so`, `therefore`, purpose clauses, method roles, mechanism stories, intuition, and closing synthesis—not only headline facts. Each span needs the exact source owner and semantic role. Delete any plausible but unlicensed bridge.
3. **Compare first and last names for every object.** Treatment, outcome, proxy, latent construct, realized statistic, parameter, counterfactual, population, unit, baseline, horizon, direction, magnitude, uncertainty, and hierarchy must retain the manuscript's exact identity whenever restated. A narrow result never broadens into a related construct.
4. **Separate result from explanation.** Association is not causation; mechanism-consistent evidence is not an identified mechanism; a method label is not a study-specific function; a proposition is not an unstated proof intuition. User requests for intuition do not authorize completion from disciplinary convention.
5. **Verify literature member by member.** A finite packet does not establish a growing field, research conversation, consensus, global gap, firstness, novelty, necessity, or what all other models cannot show. Every contribution has a verified manuscript side and prior-work side.
6. **Check hierarchy and repetition.** The question, approach, answer, credibility, primary finding, indispensable boundary, and defensible positioning are present. Delete generic importance, routine checks, low-priority detail, repeated limitations, and a second telling of the central result that adds no necessary information. Exact headline magnitudes normally appear once.
7. **Check promises and navigation.** Every advertised result and contribution maps to the body. Every roadmap section number and responsibility appears in supplied materials. The opening question, answer, contribution, and closing preserve the same subject and inferential status.

If any check fails, narrow, replace with the exact source term, delete, or ask only when the conflict truly blocks an honest final text. Rerun all seven checks after every change. Return the passing candidate verbatim and add nothing.
