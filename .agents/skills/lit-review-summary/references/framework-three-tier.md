# The Three-Tier Literature-Review Framework

This is the default framework the skill applies. It is a direct, cleaned copy of the rubric in `paper-summary-lit-review2.txt`. If the user supplies a custom framework file (`framework: <path>`), read that file instead and use its structure in place of everything below.

A literature review needs three layers: a deep per-paper sheet, a one-row-per-paper cheat sheet, and a themes-by-studies synthesis matrix. Each layer serves a different moment in the writing process.

---

## Tier 1 — Comprehensive Reference Sheet (one per paper)

Use this when reading the paper for the first time. It forces critical engagement. Every summary subagent must produce a file with exactly these seven sections, each fully populated.

1. **Bibliographic Anchor**
   - APA 7th / MLA citation (full, for the reference manager). If authors, journal, or year cannot be determined from the PDF, mark `[inferred]`.
   - Access: DOI / URL.
   - Type: Empirical / Theoretical Review / Meta-Analysis / Case Study / Essay / Report / Book.

2. **Core Argument (the "so what")**
   - Research Question / Hypothesis: what problem are they trying to solve?
   - Main Argument (Thesis): in one sentence, the central claim.
   - Contribution to the field: how does this fill a gap or challenge existing knowledge?

3. **Methodology (the "how")**
   - Method / Design: e.g., qualitative interviews, quantitative RCT, mixed methods, narrative synthesis.
   - Data Source / Sample: who or what was studied (size, demographics, scope, dates).
   - Key Variables / Concepts: independent/dependent variables or core constructs.

4. **Evidence & Findings (the "what")**
   - Key Results: the 3-5 most important findings, stated with numbers/effects, not vibes.
   - Data Visualization: briefly describe key graphs, models, or tables (e.g., "Figure 2 shows a positive correlation between X and Y").
   - Unexpected Outcomes: anything surprising or negative.

5. **Critical Analysis (the "why you should trust it")**
   - Strengths: e.g., large sample, novel methodology, longitudinal data.
   - Limitations: e.g., self-report bias, lack of generalizability, correlational design.
   - Bias: ideological or theoretical lean.

6. **Synthesis Links (the "connection")**
   - Supports: which other papers / literatures does this agree with?
   - Contradicts: which does it disagree with?
   - Extends: how does it build on earlier work (cite specific authors where possible)?

7. **The "Quotable" Lines**
   - 1-2 powerful verbatim sentences that capture the author's tone or argument, each with a page number.

**Quality bar for Tier 1:** "Positive correlation" is bad; "beta = 0.34 (p<0.01), 1990-2018" is good. If something is not in the paper, write "Not addressed" rather than inventing it.

## Tier 2 — Cheat Sheet (bullet points for writing)

One row per paper. Use this when actually drafting the literature review to scan sources quickly.

| Citation | Core Thesis | Method | Key Finding | Gap/Limitation | Connection |
| :--- | :--- | :--- | :--- | :--- | :--- |
| (Author, Year) | X causes Y because... | Survey (N=500) | Positive correlation | Cross-sectional; can't prove causality | Supports Smith (2020) |

## Tier 3 — Synthesis Matrix (the heart of the lit review)

Organized by **theme, not chronology**. This is the most important artifact: it is where the "empty space" the new research will fill becomes visible.

| Theme / Sub-heading | Study A | Study B | Study C | Synthesis (what we know) |
| :--- | :--- | :--- | :--- | :--- |
| Definition of key concept | Defines X as... | Uses Y to define X... | Broadens X to include Z... | *Conflict between definitions A and B; C offers a middle ground.* |
| Evidence for Argument 1 | Supports with data | Supports with data | Contradicts (says no) | *Most evidence supports, but C suggests a moderating variable.* |
| Methodological issues | Small sample | Good stats | Qualitative depth | *Studies lack longitudinal data.* |

Use a consistent marking system in cells so the "debate map" is legible at a glance:
- ✅ supports
- ❌ contradicts
- ➕ extends
- — not addressed

Follow each mark with a 3-6 word phrase. The final "Synthesis" column states, in 1-2 sentences per row, what the literature collectively establishes and where the live debate is.

---

## Two pro-tips to pass on to the user
1. **Color code.** Treat ✅ (Supports) and ❌ (Contradicts) as the debate map. The gaps between them are where a new paper lives.
2. **Always note the gap.** The purpose of a literature review is to find the empty space the user's research will fill. The Tier 3 synthesis matrix is where that space is mapped.
