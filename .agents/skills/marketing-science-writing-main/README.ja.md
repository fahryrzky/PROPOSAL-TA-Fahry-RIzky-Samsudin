# マーケティングサイエンス 学術論文作成スキル

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

OpenCode / Claude Code / Codex 向けのマーケティングサイエンス学術論文作成スキル。トピック選定から消費者効用モデリング、識別戦略の設計、構造推定、反実仮想シミュレーション、完全な初稿までをカバーします。

UTD-24 トップジャーナル **Marketing Science, JMR, JM, JCR** と、フィールドジャーナル **JAMS, IJRM, QME, Marketing Letters** の計8誌に対応。

## 機能

AIエージェントを **0→初稿 5ステージパイプライン** でガイドします：

| ステージ | 成果物 | 主な出力 |
|---------|--------|---------|
| **S1**: トピック選定 | ギャップ表、ジャーナル推薦、貢献ステートメント | どのジャーナルか + 何が新しいか |
| **S2**: 消費者効用モデル | 記法体系、効用関数の特定化、需要導出 | §3 モデル章 草案 |
| **S3**: 識別と推定 | 識別戦略（DID/RDD/IV）、推定方法、特定化検定 | §4 方法章 草案 |
| **S4**: 反実仮想と実験 | 反実仮想設計、コンジョイント分析、フィールド/ラボ実験 | §5-6 結果章 草案 |
| **S5**: 執筆・組立 | Introduction、文献レビュー、マーケティング示唆、Abstract | 完全初稿 |

**ドメイン特化型**：マーケティングジャーナル固有の慣習（消費者効用モデルの構造、識別戦略の正当化（DID, RDD, IV）、構造推定（BLP, GMM）、コンジョイント分析設計、反実仮想シミュレーションのワークフロー、査読者期待など）を内蔵しています。

## 4つの方法論的柱

### 1. 構造モデル (BLP)

消費者効用のミクロ的基礎 → ランダム係数ロジットによる集計需要 → 供給側の価格設定ゲーム → BLP/GMM推定。効用関数の特定化（内生価格、外生的製品特性、ランダム係数）、モーメント条件の構築（需要側・供給側・マイクロモーメント）、最適重み行列を用いたGMM目的関数までをガイドします。

### 2. 因果推論 (DID / RDD / IV)

自然実験、準実験デザイン、操作変数戦略によるマーケティングにおける因果効果の識別。段階的導入のDID、マーケティング文脈での回帰不連続デザイン（政策閾値、ランキングカットオフ）、IVの構築（Hausman操作変数、BLP操作変数、コストシフター）をカバー。

### 3. フィールド実験

マーケティングにおけるランダム化フィールド実験の設計と分析 — デジタルA/Bテスト、実店舗実験、価格設定実験。統計的検出力分析、ランダム化チェック、異質性を伴う処置効果の推定、構造モデルとの連携を含む。

### 4. 反実仮想シミュレーション

構造モデル推定後：反実仮想シナリオでの結果予測（合併シミュレーション、価格差別禁止、新製品導入、広告上限）。反実仮想世界での均衡計算、厚生分析（消費者余剰、生産者利潤、総厚生）、反実仮想結果とマーケティング示唆の接続をガイドします。

## インストール

### 1. リポジトリのクローン

```bash
git clone https://github.com/liyuanbo1024/marketing-science-writing.git
```

### 2. AIエージェントへのインストール

| エージェント | インストールコマンド |
|-------------|-------------------|
| **OpenCode** | `cp -r marketing-science-writing ~/.config/opencode/skills/` |
| **Claude Code** | `cp -r marketing-science-writing ~/.claude/skills/` |
| **Codex** | `cp -r marketing-science-writing ~/.agents/skills/` |
| **Cursor** | `cp -r marketing-science-writing ~/.cursor/skills/` |
| **Windsurf** | `cp -r marketing-science-writing ~/.windsurf/skills/` |

インストール後、自然言語でスキルを起動できます：
- `スマートフォン市場のBLP需要推定の論文を書きたい。ポジショニングを手伝って`
- `消費者効用モデルができた。操作変数の識別戦略を設計して`
- `マーケティングサイエンスの論文執筆パイプラインを全部通して`

## 使い方

### パイプラインモード

```
「マーケティングサイエンスの論文執筆パイプラインを実行して。私のトピックは…」
```

エージェントが現在の段階を評価し、S1→S5まで順次実行。各段階で確認を取ります。

### ステージジャンプ

| トリガーフレーズ | ジャンプ先 |
|----------------|----------|
| 「研究アイデアがある…」 | S1: トピック選定 |
| 「消費者効用モデルを設計して」 | S2: 効用モデル |
| 「識別戦略を設計して」 | S3: 識別と推定 |
| 「反実仮想シミュレーションを設計して」 | S4: 反実仮想と実験 |
| 「完全な論文を書いて」 | S5: 執筆・組立 |

### リファレンスモード

```
「Marketing Scienceの識別戦略に対する査読基準は？」
「JMRのコンジョイント分析はどう設計すべき？」
「差別化製品市場の標準的な効用関数の特定化は？」
```

## 主なリジェクト理由

| 理由 | 頻度 | 防止策 |
|------|------|--------|
| 識別戦略が弱い | 非常に高い | 操作変数または自然実験の明示的な正当化 |
| 内生性が未処理 | 非常に高い | 需要推定では必ず価格内生性に対処 |
| 文献への貢献が不十分 | 高い | Introductionに明確なGap Table |
| 反実仮想シナリオに政策関連性がない | 高い | 実際のマーケティング意思決定に基づく |
| マーケティング示唆が一般的すぎる | 高い | 具体的・番号付き・推定結果に追跡可能 |
