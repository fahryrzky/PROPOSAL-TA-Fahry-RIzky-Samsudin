# 마케팅 사이언스 학술 논문 작성 스킬

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

OpenCode / Claude Code / Codex 등 AI 코딩 에이전트를 위한 마케팅 사이언스 학술 논문 작성 스킬입니다. 주제 선정부터 소비자 효용 모델링, 식별 전략 설계, 구조 추정, 반사실 시뮬레이션, 완전한 초고까지 전 과정을 다룹니다.

UTD-24 최상위 저널 **Marketing Science, JMR, JM, JCR**을 비롯해 **JAMS, IJRM, QME, Marketing Letters**까지 총 8개 저널을 지원합니다.

## 기능

AI 에이전트가 마케팅 사이언스 논문의 **0→초고 5단계 파이프라인**을 수행하도록 안내합니다:

| 단계 | 산출물 | 주요 결과물 |
|------|--------|-----------|
| **1단계**: 주제 선정 | Gap table, 저널 추천, 기여문 | 어느 저널 + 무엇이 새로운가 |
| **2단계**: 소비자 효용 모델 | 표기 체계, 효용 함수 설정, 수요 도출 | §3 모델 섹션 초고 |
| **3단계**: 식별과 추정 | 식별 전략(DID/RDD/IV), 추정 방법, 설정 검정 | §4 방법 섹션 초고 |
| **4단계**: 반사실과 실험 | 반사실 설계, 컨조인트 분석, 필드/랩 실험 | §5-6 결과 섹션 초고 |
| **5단계**: 집필 및 조립 | Introduction, 문헌 검토, 마케팅 시사점, Abstract | 완전한 초고 |

**도메인 특화**: 일반 작성 스킬이 다루지 않는 마케팅 저널 고유의 관행(소비자 효용 모델 구조, 식별 전략 정당화(DID, RDD, IV), 구조 추정(BLP, GMM), 컨조인트 분석 설계, 반사실 시뮬레이션 워크플로우, 심사자 기대치 등)을 내장하고 있습니다.

## 4대 방법론 기둥

### 1. 구조 모델 (BLP)

소비자 효용의 미시적 기초 → 랜덤 계수 로짓을 통한 집계 수요 → 공급 측 가격 설정 게임 → BLP/GMM 추정. 효용 함수 설정(내생적 가격, 외생적 제품 특성, 랜덤 계수), 적률 조건 구축(수요 측·공급 측·마이크로 적률), 최적 가중치 행렬을 사용한 GMM 목적 함수까지 안내합니다.

### 2. 인과 추론 (DID / RDD / IV)

자연 실험, 준실험 설계, 도구 변수 전략을 통한 마케팅에서의 인과 효과 식별. 단계적 도입 DID, 마케팅 맥락에서의 회귀 불연속 설계(정책 임계값, 순위 컷오프), IV 구축(Hausman 도구 변수, BLP 도구 변수, 비용 변동 요인)을 다룹니다.

### 3. 필드 실험

마케팅에서의 무작위 필드 실험 설계와 분석 — 디지털 A/B 테스트, 오프라인 매장 실험, 가격 책정 실험. 통계적 검정력 분석, 무작위화 검증, 이질적 처치 효과 추정, 구조 모델과의 연결을 포함합니다.

### 4. 반사실 시뮬레이션

구조 모델 추정 후: 반사실 시나리오에서의 결과 예측(합병 시뮬레이션, 가격 차별 금지, 신제품 도입, 광고 상한). 반사실 세계에서의 균형 계산, 후생 분석(소비자 잉여, 생산자 이윤, 총 후생), 반사실 결과와 마케팅 시사점의 연결을 안내합니다.

## 설치

### 1. 저장소 클론

```bash
git clone https://github.com/liyuanbo1024/marketing-science-writing.git
```

### 2. AI 에이전트에 설치

| 에이전트 | 설치 명령어 |
|---------|-----------|
| **OpenCode** | `cp -r marketing-science-writing ~/.config/opencode/skills/` |
| **Claude Code** | `cp -r marketing-science-writing ~/.claude/skills/` |
| **Codex** | `cp -r marketing-science-writing ~/.agents/skills/` |
| **Cursor** | `cp -r marketing-science-writing ~/.cursor/skills/` |
| **Windsurf** | `cp -r marketing-science-writing ~/.windsurf/skills/` |

설치 후 자연어로 스킬을 호출할 수 있습니다:
- `스마트폰 시장의 BLP 수요 추정 논문을 쓰고 싶습니다. 포지셔닝을 도와주세요`
- `소비자 효용 모델이 완성되었습니다. 도구 변수 식별 전략을 설계해 주세요`
- `마케팅 사이언스 논문 작성 파이프라인 전체를 실행해 주세요`

## 사용법

### 파이프라인 모드

```
"마케팅 사이언스 논문 작성 파이프라인을 실행해 주세요. 제 주제는…"
```

에이전트가 현재 단계를 평가하고 1단계부터 5단계까지 순차적으로 실행하며, 각 단계마다 확인을 요청합니다.

### 단계 건너뛰기

| 트리거 문구 | 이동 단계 |
|-----------|---------|
| "연구 아이디어가 있습니다…" | 1단계: 주제 선정 |
| "소비자 효용 모델을 설계해 주세요" | 2단계: 효용 모델 |
| "식별 전략을 설계해 주세요" | 3단계: 식별과 추정 |
| "반사실 시뮬레이션을 설계해 주세요" | 4단계: 반사실과 실험 |
| "완전한 논문을 작성해 주세요" | 5단계: 집필 및 조립 |

### 참조 모드

```
"Marketing Science의 식별 전략 심사 기준은 무엇인가요?"
"JMR의 컨조인트 분석은 어떻게 설계해야 하나요?"
"차별화된 제품 시장의 표준 효용 함수 설정은 무엇인가요?"
```

## 주요 거절 사유

| 사유 | 빈도 | 예방책 |
|------|------|--------|
| 식별 전략이 취약함 | 매우 높음 | 도구 변수 또는 자연 실험의 명시적 정당화 |
| 내생성이 처리되지 않음 | 매우 높음 | 수요 추정 시 반드시 가격 내생성에 대처 |

| 반사실 시나리오의 정책 관련성 부족 | 높음 | 실제 마케팅 의사 결정에 근거 |
| 마케팅 시사점이 지나치게 일반적 | 높음 | 구체적·번호 부여·추정 결과에 추적 가능 |
