# write-grant-proposal / 中文申请书写作 Skill

[English](README.en.md)

一个用于中文基金申请书、专项申报书、企业揭榜方案和技术实施方案写作的 Codex Skill。它把申请书写作拆成可执行流程：先读模板和指南，再确定方法体系，随后生成大纲、填充正文，并做全文一致性自检。

## 适用场景

- 产学研基金申请书
- 自然科学基金申报书
- 专项项目申报书
- 企业揭榜挂帅方案
- 技术实施方案
- 已有草稿的结构重写、技术路线补写、指标体系整理和全文一致性审查

## 核心能力

- **模板优先**：先解析申请书模板，保留原始章节、层级、表格和格式要求。
- **指南映射**：把指南中的研究内容、考核指标、交付成果和限制条件映射到具体章节。
- **方法体系设计**：先确定总技术主线、研究内容分解、方法命名、标题对应和指标映射。
- **大纲冻结**：正文写作前先形成完整章节大纲，避免边写边改导致结构失控。
- **章节写作**：覆盖概述、研究目标、研究内容、技术路线、创新点、进度安排、考核指标和预期成果。
- **全文自检**：检查模板完整性、标题一致性、指标一致性、术语一致性、主语一致性和脱敏安全。
- **开源脱敏**：只保留从优秀申请书中抽象出的写作规律，不包含任何私有项目、私有文件或具体本子内容。

## 推荐工作流

1. 准备申报指南、申请书模板、已有草稿和补充材料。
2. 让 Codex 使用本 Skill 先输出“模板解析 + 方法体系 + 完整大纲”。
3. 确认大纲后，再逐节填充正文。
4. 正文完成后运行全文一致性自检。
5. 根据自检结果统一修订标题、术语、方法名、指标、成果和交叉引用。


```text

```

## 设计原则

- 不直接套用固定模板，因为每个本子的模板、章节、字段和评审要求都不同。
- 不跳过大纲阶段，因为研究内容、技术路线、创新点、指标和成果必须先对齐。
- 不编造指标、团队成果、外部数据或指南没有要求的承诺。
- 不复用私有文本原文，只抽象结构规律、论证节奏和写作方法。
