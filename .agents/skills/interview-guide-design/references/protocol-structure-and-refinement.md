# 提纲结构与精炼：IPR 四阶段 / Protocol Structure & Refinement

搭整份提纲结构、做研究问题—访谈题映射、做近读核查、检索同主题成熟提纲时读本文件。核心框架是 Castillo-Montoya（2016）的**访谈提纲精炼框架（Interview Protocol Refinement, IPR）**。

## 0. 检索同主题成熟提纲（出题前）

质性**没有可原样套用的标准化量表**，但有可借鉴的**结构与维度**。出题前去找：
- 同主题/同领域**已发表研究的访谈 protocol**（很多刊在论文附录或补充材料）；
- **机构化/基金课题的结构性访谈提纲**（如国家社科基金课题的附录访谈提纲——典型结构：致辞 → 基本信息 → 分主题板块的开放问题 → 成效/问题）；
- 同主题**学位论文附录**的访谈提纲。

**借结构、借维度（分哪几块、问到哪些层面），不照抄题面**。看完在映射矩阵里说明你借鉴了什么、改了什么。

## 1. IPR 四阶段总览（Castillo-Montoya, 2016, *The Qualitative Report*, 21(5), 811–831）

| 阶段 | 做什么 | 本 skill 在哪一步 |
|---|---|---|
| **Phase 1** 对齐 | 确保访谈问题对齐研究问题 | 工作流第 1 步（映射矩阵） |
| **Phase 2** 构建探询式对话 | 把提纲组织成自然的对话流 | 工作流第 3–4 步（出题 + 组装） |
| **Phase 3** 获取反馈 | 外部评审提纲（近读核查表） | 后续清单（专家评审） |
| **Phase 4** 试访 | 在真实情境 pilot | 后续清单（pilot） |

## 2. Phase 1：研究问题—访谈问题映射矩阵

**核心提醒（Castillo-Montoya 的招牌洞见）**：研究问题是写给**同行**看的（学术语域），访谈问题是说给**受访者**听的（日常语域）——**绝不能把研究问题原样抛给受访者**。映射矩阵是把前者翻译成后者，并保证不遗漏、无孤儿。

做一张表：

| 研究问题(RQ) | 访谈问题编号 | 这道访谈题想挖什么 |
|---|---|---|
| RQ1 … | Q3, Q4, Q7 | … |
| RQ2 … | Q5, Q8 | … |

自检：每个 RQ 至少有题覆盖（无遗漏）；每道访谈题都挂到某 RQ（无孤儿，孤儿题删或改）。这等价于量化里"每题服务一个构念"。

## 3. Phase 2：四段式对话流

把题组织成一场自然对话（Castillo-Montoya 建议的 background / transition / key / closing 四段）：

1. **开场（background / 基本信息）**：
   - 研究者自我介绍、研究目的一句话、保密与录音知情同意、可随时退出。
   - 易答的背景题暖场（岗位职责、从业时长等）——降低紧张、建立融洽。
2. **过渡题（transition）**：从背景平滑过渡到核心，宽松的大游览问题放这里。
3. **核心题（key）**：按研究问题/主题成块。**敏感题靠后**。每题标注服务哪个 RQ、主问题/追问/探测、是否敏感。
4. **收尾（closing）**：
   - **兜底题（必给）**：「还有什么是我没问到、但您觉得重要的吗？」——精英/关键知情人常在此抖出最有价值的信息（Solarino & Aguinis, 2021）。
   - 致谢、说明后续（是否回访做成员核验）。

## 4. 两版提纲：现场简版 vs 准备详版

- **详版**：含所有主问题 + 预备追问 + 探测，研究者**准备时**用。
- **简版**：只列主问题/主题词，**现场带这版**——逼自己真正去听受访者讲，而不是埋头念长稿。

## 5. Phase 3：近读核查表（写完自检 + 专家评审）

Castillo-Montoya 的"近读核查表（Activity Checklist for Close Reading）"约 15 条，**朗读每一题**逐条判 yes/no。核查四个面向：

- **提纲结构**：开场—过渡—核心—收尾齐全？敏感题靠后？大游览开场？映射矩阵无孤儿？
- **问题写法**：开放式？非诱导？无双重负载？无术语黑话？无生硬质问？落到具体经历而非抽象？
- **长度**：单题是否过长绕口？整场题量是否撑得满又不超时（60–90 分钟约 5–10 主问题）？
- **可理解性**：受访者一听就懂？用词贴合该人群（精英/普通/特定群体）？

**朗读很关键**——很多绕口、诱导、双重负载的毛病只有读出声才暴露。专家评审则把提纲交给同行/导师按此表近读，回反馈再改（提升提纲作为工具的可信度）。

## 6. Phase 4：试访（pilot，写进后续清单）

正式开访前找 1–2 个符合条件的人试访：检验题目是否被如预期理解、追问是否顺、时长是否合适、有没有该删/该补的题。记录每道题"用了/删了/改了"及理由——这既精炼提纲，也是 dependability（可追溯）的证据。

> 出处：Castillo-Montoya, M. (2016). Preparing for Interview Research: The Interview Protocol Refinement Framework. *The Qualitative Report, 21*(5), 811–831. 引用前 web 核查，见 `sources.md`。
