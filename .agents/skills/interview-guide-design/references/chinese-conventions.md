# 中文访谈提纲惯例 / Chinese-Language Conventions

产出中文访谈提纲、要符合中文期刊/基金课题审稿习惯、访谈官员或管理者时读本文件。

## 1. 中文"结构性访谈提纲"的典型格式

中文社科调研（尤其国家社科基金、政府课题、学位论文）里"结构性/结构化访谈提纲"有一套约定俗成的样子，参考典型结构（如县域城镇化、乡村振兴类课题）：

```
附表X  [主题] 结构性访谈提纲

[致辞/称呼]：尊敬的 ×× 领导/同志：
  您好，我们是 ×× 研究团队（经 ×× 引荐 / 经 ×× 单位同意开展），正在了解 ×× 情况。您的回答将帮助我们 ……，
  访谈内容严格保密、匿名化（去标识化）呈现，仅用于学术研究，请根据实际情况放心作答。感谢支持！

一、基本信息
   年龄、政治面貌、岗位职责等

二、[主题板块1：基本情况]
   1. 请介绍一下 ……
   2. …… 的主要特色是什么？

三、[主题板块2：主要举措]
   3. …… 采取了哪些措施？
   4. 请介绍一下 …… 的思路与做法。

四、[主题板块3：主要成效与问题]
   …… 取得了哪些成效？还存在哪些困难？
```

要点：
- **开头有正式致辞**：称呼（对官员/管理者用"尊敬的××领导/同志"）、自我介绍、研究目的、匿名承诺、致谢。
- **基本信息**单列一节（岗位职责等，不是量化人口学那套精确分段）。
- **主题板块化**：按"基本情况 → 主要举措/做法 → 主要成效与问题"递进，每板块下编号开放题。
- **题面多用**"请介绍一下……""……是什么""……有哪些做法"——开放、邀请叙述，不是封闭打分。

这套格式服务于**关键知情人/精英访谈**（问的是管理者、官员视角的政策与做法），与问卷问普通群众是两端，常在同一调研里配合使用（一个铺广度、一个挖治理侧）。

## 2. 对官员/管理者的敬语与姿态

- 称呼用"××领导""××主任""××经理""老师"等，落到对方身份。
- 提问姿态：请教、请其"介绍/分享/谈谈"，给足专业展示空间，别像查户口。
- 访前做足功课、建立专业可信度；遇到确实不懂处可坦诚请教，**不要不懂装懂**（既保研究者诚信，也不至于因外行话被精英轻视）。
- ⚠ **别承诺"完全匿名"**：访谈领导/管理者时，"岗位 + 单位"常足以反推身份（一个县往往只有一位某局局长）。方法学上要分清 **anonymity（真匿名，研究者也认不出）vs confidentiality（保密，认得出但不披露）**——面对面具名访谈只能做到后者。致辞用"严格保密、匿名化呈现"，必要时与受访者协商化名/模糊化（详见 `trustworthiness-and-sampling.md` §4）。

## 3. 中文质性审稿常被查的点

中文期刊审质性研究，常要求体现：
- **三角验证**：多源数据互相印证（横向访不同层级、纵向比历史档案/统计/文件）。
- **展示访谈提纲**：把提纲附在论文里本身就是提升信度/可靠性的手段。
- **可信度策略**：成员核验（成员核查）、同侪核验（同侪简报）、偏差案例分析。
- **理论抽样**：说明为何选这些案例/受访者。
- **文献比较**：理论构建型案例研究把结论与既有文献对照——中文规范视为"点睛之笔"。
- **研究伦理**：知情同意、隐私、守诺。

## 3.5 个人信息合规（PIPL）——中文 skill 不可省的合规层

访谈会采集姓名、岗位、机构、履历、录音等个人信息，访官员更触及职务履历。《个人信息保护法》（PIPL，2021-11 施行）的要点要对接进知情同意与数据处理（落笔前按核查纪律 web 核对条款号）：

- **告知—同意（第 14 条）**：同意须在**充分知情**下**自愿、明确**作出；处理目的/方式/种类变更要重新取得同意。
- **敏感个人信息的单独同意（第 28、29 条）**：敏感个人信息含医疗健康、宗教信仰、特定身份、金融账户、行踪轨迹、生物识别及不满 14 周岁未成年人信息等；处理须有特定目的与充分必要性，并取得**单独同意**（与其他事项分开、单列勾选，而非一揽子概括同意）。⚠ 别把"录音=声纹=生物识别"当铁律——普通录音未必构成声纹这类生物识别 SPI，**但访谈内容常携带 SPI**，故从严处理为宜。
- **特别告知（第 30 条）**：处理敏感个人信息还要告知其必要性与对个人权益的影响。
- **去标识化 vs 匿名化（第 73 条）**：去标识化后仍属个人信息、仍受 PIPL 约束；**匿名化（不可复原）后不再属于个人信息**、可脱离 PIPL。访谈数据应**尽早去标识化**，对外发布结果用匿名化/高度概括口径。
- **留存与跨境**：明确用途、留存期限、销毁；同意记录宜留存以备合规说明（PIPL 未设 GDPR 式"可追溯证明"问责条款，别夸大成法定要求）；数据出境另有规则，涉及时再提示。

落地：开场白把"告知—自愿同意—录音单独同意—去标识化—用途/留存/销毁—可撤回"讲清；同意书做成多段勾选（见模板）。

## 3.6 中文质性方法节推荐骨架（写论文方法章时对照）

中文期刊/学位论文的质性方法节常按这个骨架走，每段都要**挂对应方法论文献**撑住声称：

1. **研究设计与取向**（案例研究/扎根理论…；Yin 还是 Stake）
2. **案例与边界**（为什么是这个案例、边界在哪）
3. **抽样逻辑**（目的性/理论抽样、选样标准、样本量与饱和判断）——审稿高频必报
4. **数据收集**（访谈 + 多源证据；附**访谈提纲**本身——展示提纲即提升可靠性）
5. **可信度策略**（逐准则：三角验证、成员核验、同侪核验、审计轨迹、反身性）
6. **研究伦理与数据合规**（伦理审查批件号、知情同意、PIPL 去标识化）

## 5. 核查纪律

中文方法论文献同样要 web 核查：框架提出者、年份、核心主张、阈值归属。常见幻觉——把"结构化访谈"等同于"质性"（其实结构化是标准化程度，开放式答案才让它质性）、把饱和人数当无条件铁律、把可信度四准则张冠李戴。核不实就标"待核"或删。
