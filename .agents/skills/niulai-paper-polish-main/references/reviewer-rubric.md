# General peer-review rubric

Use this only when the target venue supplies no current rubric. Adapt the labels, not the scientific standard.

| Dimension | Core question | Typical fatal gap | Prose can help when |
| --- | --- | --- | --- |
| Correctness / soundness | Do methods and evidence support the claims? | Invalid design, leakage, wrong analysis, unsupported inference | The valid method or evidence is present but underspecified |
| Significance | Would the result matter to the venue's community? | Trivial delta with no demonstrated consequence | The consequence exists but is not connected to the result |
| Novelty | What exactly changes relative to closest prior work? | Material prior art already provides the same contribution | The delta is real but buried or described too broadly |
| Evidence | Are baselines, uncertainty, ablations, and failure cases adequate? | Required evidence is absent | Existing evidence is scattered or not interpreted |
| Clarity / reproducibility | Could a specialist understand and reproduce the work? | Missing settings, data provenance, or algorithm details | Details exist but terminology and organization obscure them |
| Ethics / limitations | Are risks, scope, and limitations honestly handled? | Missing approval, consent, disclosure, or serious unaddressed harm | Statements are present but incomplete or misplaced |

## Diagnostic rating

For each dimension, record:

- current assessment and exact manuscript evidence;
- presentation-only revision that is possible now;
- scientific work that would be needed for a true improvement;
- residual uncertainty or likely reviewer disagreement.

Do not collapse this into a fabricated acceptance probability. If a numeric venue scale is needed, quote the venue's official anchors and state that the score is an estimate from one review pass.
