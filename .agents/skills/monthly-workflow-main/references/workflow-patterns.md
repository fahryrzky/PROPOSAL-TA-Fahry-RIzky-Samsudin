# Workflow Patterns

Use this reference when adapting the monthly workflow to a specific domain.

## Research / Study

Common workstreams:

- Paper or thesis writing
- Experiments or coding
- Reading and idea development
- Advisor or group meeting communication

Useful completion standards:

- Draft section completed
- Experiment command, output, and blocker recorded
- Paper note added with reusable insight
- Advisor feedback converted into a task list

## Coding / Product

Common workstreams:

- Feature implementation
- Testing and QA
- Documentation
- Release or demo preparation

Useful completion standards:

- Feature merged or locally verified
- Tests run and result recorded
- Demo path works
- Known bugs recorded with reproduction steps

## Learning / Personal Development

Common workstreams:

- Course progress
- Practice tasks
- Review and spaced repetition
- Portfolio output

Useful completion standards:

- Lesson completed with notes
- Exercise set completed and mistakes reviewed
- Practice duration and result recorded
- Output artifact created

## Team / Collaboration

Common workstreams:

- Shared deliverables
- Meeting preparation
- External requests
- Follow-up tracking

Useful completion standards:

- Deliverable sent or ready for review
- Meeting notes converted into actions
- Owner and deadline recorded
- Waiting-on items separated from active tasks
