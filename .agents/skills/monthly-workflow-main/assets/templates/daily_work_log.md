# Daily Work Log

> Purpose: daily plan, check-in, actual progress, blockers, review, and tomorrow's first task.

## Rules

- Choose at most one daily main goal.
- Use 3-6 task nodes.
- Give every task a completion standard.
- Record partial work honestly.
- Write tomorrow's first task before closing the day.
