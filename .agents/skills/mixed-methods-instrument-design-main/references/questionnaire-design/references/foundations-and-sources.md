# 问卷基础、构念与来源检索

## 1. 先判断是否应使用问卷

问卷适合收集受访者能够标准化报告的事实、行为、知识、态度、感知与结果。行政记录更准确时不要重复要求回忆；机制、意义和未知答案空间需要访谈或观察时，保留其他资料来源。问卷无法替代直接行为记录，也无法让回答者评价其不可观察的组织或他人状态。

## 2. 用总调查误差组织风险

Groves 与 Lyberg 的总调查误差（TSE）用于在设计阶段同时考虑误差与成本，不把注意力只放在抽样误差。建立两条风险链：

| 表征链 | 测量链 |
|---|---|
| 目标总体 → 抽样框 → 样本 → 响应者 → 加权估计 | 构念 → 操作化 → 题面/模式 → 回答 → 编码/处理 |
| 覆盖、抽样、无应答、调整误差 | 构念效度、测量、访员/模式、处理误差 |

问卷设计主要控制测量链，但必须向抽样与现场分支传递总体、抽样框、回答负担和敏感性风险。不要把“无抽样误差”误写成“没有误差”。

## 3. 建立构念—变量规格

每个构念或变量记录：

- 概念定义、理论角色和与邻近概念的区别；
- 包含/排除内容、时间窗、参照对象和单位；
- 目标总体、回答者、观察单位与分析单位；
- 反映型潜变量、形成型指数、单项事实还是分类变量；
- 候选指标、期望变异、计划分析和决策后果；
- 可能误差、替代数据源和不宜由谁回答。

反映型量表项目预期由共同潜变量解释；形成型指数由组成成分定义。二者的项目选择、相关性期待和验证逻辑不同，不能仅凭软件输出互换。

## 4. 来源检索层级

按下列顺序 Web 检索并保存检索式、日期和结果：

1. 原始开发论文、原作者手册、出版者或工具所有者页面；
2. 政府统计机构、国际组织、国家级研究项目的正式问卷；
3. 与当前目标人群、语言、模式和用途匹配的独立验证研究；
4. 系统综述或工具数据库，用于发现候选工具；
5. 同主题经验研究，用于事实分类、回忆期和领域措辞。

优先核对完整题面、选项、说明、回忆期、计分、版本、许可和适用样本。只看到工具名称、总分或二手转引时，不得反推原题。

## 5. 逐题来源状态

| 状态 | 使用条件 | 输出措辞 |
|---|---|---|
| `validated` | 版本、语言、题面、选项、回忆期、计分、用途和人群均与证据相符 | “采用某版本；既有证据见……” |
| `adapted` | 发生翻译、删改、换人群/模式/情境/选项/回忆期或计分 | “改编题项，当前用途待验证” |
| `official` | 来自官方调查工具 | “官方来源题项”；不自动称成熟量表 |
| `new` | 本研究新编 | “新编待验证题项” |

“validated”并非永久标签。既有证据支持的是特定分数解释、用途、样本和实施条件。将多份成熟量表中的题拼接成新组合时，新组合仍需验证。

## 6. 许可与版本

- 记录 copyright、许可类型、是否允许翻译/改编/电子化和是否需付费授权。
- 安全测验、商业量表或许可不明工具只给名称、出处和取得路径，不大量复制题目。
- 记录原版本号、本地版本号、改动者、日期、改动原因和影响题号。
- 趋势研究若改变题面、题序、模式或选项，必须建立桥接/并行测试；“意思差不多”不足以保持时间可比性。

## 7. 来源记录表

至少包含：检索式与日期、数据库/网站、来源类型、工具名和版本、构念、人群、语言、模式、题项/选项/回忆期、计分、证据类型、许可、本次改动、状态和 URL/DOI。

方法底座与适用范围见 `sources.md`。具体主题仍须重新检索，不得用通用方法文献代替领域工具证据。
