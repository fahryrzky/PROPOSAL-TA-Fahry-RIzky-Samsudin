# 伦理、隐私与中国实施语境

## 1. 伦理判断前置

涉及人为调查对象或使用个人信息数据时，在招募和上线前由所属机构判断是否需要科技伦理/研究伦理审查、备案或豁免；skill 不能替代伦理委员会决定。中国《科技伦理审查办法（试行）》明确覆盖以人为测试、调查、观察对象及利用个人信息数据的科技活动。生命科学和医学研究另适用相应专门办法。

## 2. 知情同意页

按适用法律与机构要求，以目标人群能理解的语言说明：研究身份与目的、为何被邀请、预计时长、流程、风险/不适、可能利益、激励、是否自愿、可跳题/退出、退出后数据如何处理、保密边界、信息种类与用途、保存期限、共享/跨境/平台、联系人和伦理投诉渠道。

点击同意、继续作答或回寄问卷是否足够，取决于风险、司法辖区和伦理审批。不得自行宣称“无需伦理审查”或以低风险为由跳过机构判断。

## 3. 最小必要与目的限定

依据中国《个人信息保护法》，个人信息处理遵循合法、正当、必要、诚信、公开透明和最小范围，并说明目的、方式、种类、保存期限及权利行使方式。设计时逐题回答：是否为 RQ、抽样、质量或必要异质性分析所需；若无用途就删除。

姓名、手机号、精确位置、单位、职务、身份证明、设备标识和开放题细节可组合识别个人。人口学信息也可能在小群体中重识别。

## 4. 敏感信息与脆弱/从属人群

健康、生物识别、宗教、特定身份、金融账户、行踪和未成年人等信息按适用法规判断敏感性与单独同意。师生、上下级、医患、雇佣或福利关系中，明确拒绝不影响评价、待遇或服务；招募者和数据查看者尽量与权力方分离。

未成年人、认知受限者或其他需要额外保护的人群，要设计适龄信息、监护许可/本人同意或 assent、退出和风险应对，并由伦理机构确认。

## 5. 匿名、保密与去标识化

- **匿名**：研究团队无法合理识别回答者；在线平台日志、token、联系方式或小群体组合变量可能使其不成立。
- **保密**：研究者能接触身份但限制访问和披露。
- **去标识化**：移除或变换直接/间接标识，仍需评估重识别风险。

措辞必须反映真实技术流程。联系方式用于抽奖、回访或后续访谈时，优先与问卷答案分表、分权保存，通过随机 ID 连接，并说明连接及删除时间。

## 6. 数据生命周期

建立数据清单、合法依据/同意、角色权限、传输与静态加密、备份、平台所在地、第三方协议、跨境判断、保存期限、删除/销毁、泄露响应和共享条件。原始可识别数据与分析数据分离；最小权限；导出和下载留痕。

开放题提醒不要填写非必要姓名或身份细节。发布前做小单元、极端组合、原话和地理信息披露风险检查。

## 7. 欺骗、注意力检查与激励

研究需隐瞒或欺骗时必须有科学理由、最小风险、伦理批准和适当事后说明。注意力检查不得羞辱、欺骗或成为任意没收激励的工具。激励与时间负担相称，并明确部分完成、筛选退出和质量排除的支付规则。

## 8. 中国问卷表达

- 使用目标群体自然语言，保留必要敬称但避免行政口号和评价性表态。
- 官方分类、行政区划、民族、教育、职业、收入等只有分析必需时使用，并核对当期正式口径。
- 组织内部调查谨慎收集单位、岗位、级别和小部门组合，防止“名义匿名、实际可识别”。
- 平台若采集 IP、设备、微信/手机号或账号信息，要在同意与数据清单中如实写明。
- 政策文件号、法律状态、官方分类和敏感信息规则每次上线前 Web 复核，不能仅依赖本文件日期。

## 9. 交付检查

交付伦理判断待办、知情同意文本、逐字段必要性表、数据流与访问角色、联系信息分离方案、保存/删除计划、平台风险、特殊人群保护和未解决合规问题。法律/伦理内容仅作设计提醒，必要时由机构伦理与法律人员审定。
