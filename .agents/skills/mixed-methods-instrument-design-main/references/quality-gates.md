# 交付前质量闸门

逐项检查并报告“通过 / 待处理 / 不适用”。存在关键待处理项时，将产出标作草案。

## A. 研究设计

- 已写明上位混合研究问题与使用两类方法的理由。
- 已选择设计类型、时序、权重和整合点。
- 已分别说明量化与质性总体、样本、分析单位及两者关系。
- 没有默认两条管线面向同一批人。
- 序贯设计没有把尚未取得的第一阶段结果伪装成第二阶段依据。

## B. 中央映射

- 每个 RQ 至少有一个资料来源；MIXED RQ 同时有量化、质性和整合链接。
- 每个问卷题和访谈核心题都映射到 RQ。
- 共同构念定义清楚，跨人群题目符合各自知识边界。
- 没有孤儿题、孤立构念或空泛的“后续综合分析”。
- 已预设确认、扩展与不一致三类关系及复核路径。

## C. 问卷

- 已判定工具属于事实/行为调查、态度题组、潜变量量表、测验、筛查或登记表，没有混用名称与证据标准。
- 已画出总调查误差风险，区分表征链与测量链；没有用正式题面替代抽样代表性。
- 已明确目标总体、抽样框、回答者、观察单位、分析单位和预期推论。
- 每题只有一个明确回答任务；题型、回忆期和选项匹配。
- 选项尽量互斥、穷尽、平衡；不知道、不适用、拒答与缺失分开编码。
- 已按理解—检索—判断—作答四阶段和十二类红线逐题检查。
- 量尺类型、点数、中点、标签、方向、题序和随机化均有任务依据，没有默认套五点同意量尺。
- 成熟、官方、改编、新编题项逐题标记，来源和许可可追溯。
- 改题、译题和新题没有继承原工具的效度声明。
- 变量名、编码、显示/跳题、随机化、校验、缺失、计分和计划分析完整。
- 所有路径、边界值、设备、语言、模式和数据导出都有测试用例。
- 已给出目标人群认知访谈、可用性测试、field pilot、修订日志与复测计划；没有用专家审查代替受访者测试。
- 多语言/跨文化任务已使用团队翻译、审定、目标语言测试和版本记录；没有把翻译等同测量等值。
- 量表/测验已按用途规划内容、反应过程、结构、可靠性/误差、关系、公平性与后果证据；普通事实题没有被机械要求做因子分析。
- 样本取得方式、无应答、在线重复/机器人/低努力诊断、预先排除规则和敏感性分析完整。
- 已处理伦理审查判断、知情同意、最小必要、敏感信息、联系信息分离、权限、保存与删除。
- 已交付研究者设计版、受访者实施版、数据与编程版；实施版未泄漏构念、计分键和质量排除规则。
- 要求 Word 时，全部问卷 form 与访谈提纲已汇入同一份完整 DOCX；不同人群分节清楚，结构、逐页渲染、题号一致性和现场信息隔离均已检查，内部 JSON 与审查材料没有被误当成交付文件。

## D. 访谈质量锁

- 已全文读取并执行内置 `interview-guide-design/SKILL.md`。
- 已完成原 skill 的检索与出处硬闸，没有凭印象引用方法框架。
- 有 RQ—访谈题映射、主问题—追问—探测、大游览开场和兜底题。
- 已过七条质性提问红线，敏感题与权力关系处理得当。
- 已设计可信度四准则、三角验证、成员核验、反身性、立场性和负向案例。
- 已处理伦理审查、录音同意、保密、去标识化、退出与数据管理。
- 已交付研究者版、现场详版和现场简版；现场版未泄漏方法标签。
- 已给出专家 close reading、pilot、抽样/饱和与分析准备清单。

## E. 整合与报告

- 已生成适配设计类型的空白联合展示。
- 没有把不同分析单位的值直接加总或做无依据的个人层关联。
- 已分别保留量化不确定性和质性情境边界。
- 已说明混合结果如何产生额外洞见，以及可能无法整合的部分。
- 方法依据与题项来源均有可点击的真实链接；未核实内容已标待核或删除。
- 没有声称已经实施抽样、预测试、验证、访谈、编码、成员核验或正式分析。

## F. 通用性与完整性

- Skill 的规则没有硬编码当前案例的行业、地区、人群和维度。
- 示例只用于测试，不替代从用户 RQ 推导构念。
- 问卷篇幅没有压缩访谈模块；长度不足时采用分文件交付。
- 产出能在至少三个不同学科/场景中沿用相同流程而不沿用示例内容。

## G. 问卷星上线（仅在用户要求时）

- 使用问卷星官方 CLI/MCP/SDK 和公开接口，没有调用抓包所得私有接口。
- API Key 未写入 Skill、项目、文档、平台载荷、manifest、日志或回复。
- 每个 form 与线上问卷的对应关系明确；不同人群没有未经论证地合并。
- 平台载荷由已通过校验的问卷规格生成，manifest 无 blocker。
- 首次推送只创建未发布草稿，没有使用 `--publish`。
- 已回读线上草稿并核对标题、题数、题型、题面、选项、顺序、必答与章节。
- 所有筛选、显示、跳转、随机化、拒答、结束和异常路径均完成预览测试。
- Word、问卷规格、平台 JSONL 与线上草稿保持题号和版本一致。
- 只有用户针对具体问卷 ID 再次明确确认后才正式发布。
- 暂停、删除、清空答卷和修改已收数问卷均单独确认；破坏性操作已说明后果。
- 人工访谈提纲没有误推入普通问卷；如使用 AI 访谈，已单独核查功能、同意、录音和数据治理。
