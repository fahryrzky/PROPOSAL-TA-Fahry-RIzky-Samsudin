# 领域引用树

本页用于从领域关键词出发，发现一组高影响力核心论文和重要后续工作。它是发现工具，不是对整个领域的穷尽排名。

## 调用方式

- 调用 `semantic_scholar_explore_field`，把用户给出的领域或主题写成精确的英文检索词。
- 默认保留 30 篇、每个节点考察引用量最高的 20 个引用者、最多扩展两层，并限制为 12 次节点展开。只有用户明确要求时才调大参数。
- 每个被展开节点都会扫描全部 citations 分页，再选择该节点的分支 Top-K；工具不提供抽样模式。高引论文可能需要上百次分页请求，并通过检查点在限流后继续。
- 不要再由模型手工逐篇调用引用查询；候选池替换、去重、递归扩展和停止条件由工具确定性执行。

## 算法含义

工具使用“有界最佳优先引用扩展”：

1. 先按引用量取领域检索的 Top 30，形成固定容量候选池。
2. 优先展开当前引用量最高且尚未展开的论文。
3. 扫描该论文的全部引用者，按引用者自身引用量排序，只考察前 20 篇。
4. 新论文的引用量严格高于当前第 30 名时，才替换末位论文。
5. 新进入候选池的论文也可继续展开，直到达到深度或 API 调用预算。

这与 best-first search（最佳优先搜索）、Top-K reservoir（固定容量优选池）和 citation snowballing（引用滚雪球）相关，但是本项目自定义的组合策略。

## 输出解释

- 先报告检索词、参数、初始论文数、实际展开节点数、citations 分页请求数、扫描记录数、替换数和最终入选门槛。
- 每篇论文仅展示标题、年份、作者、会议或期刊、研究领域和自身引用量；对引用树发现的论文，另外标明它由哪篇论文发现及所在深度。
- 把“初始领域检索入选”与“引用树后续发现”分开说明。
- 必须展示工具返回的所有 `warnings`，并说明搜索是启发式的。

## 局限

- 引用量偏向发表时间早的论文，新论文即使重要也可能落选。
- 领域关键词会影响初始根节点；一个过宽或有歧义的词会引入无关论文。
- 全量分页会显著增加 API 请求数和耗时；引用数据在分页期间变化时，总数与返回记录数仍可能不一致。
- 不会穿过未进入 Top 30 的低引用中间论文，因此可能错过它后面的高引用工作。
