# Unified Phrase Bank

Field-specific phrase replacements for economics and finance writing.

---

## Universal Phrases (All Fields)

| Function | Phrase |
|----------|--------|
| Introducing a result | "We find that..." / "The results suggest that..." |
| Acknowledging a concern | "A potential concern is..." / "One might worry that..." |
| Addressing a concern | "To address this concern, we..." / "We account for this by..." |
| Emphasizing robustness | "The results are robust to..." / "The coefficient remains virtually unchanged when..." |
| Explaining intuition | "Intuitively,..." / "The idea is that..." |
| Transitioning | "Turning to..." / "To better understand..." / "In contrast,..." |
| Concluding | "Overall, these results suggest that..." |

## EAP Phrases

| Function | Use This | Avoid This |
|----------|----------|-----------|
| Introducing the idea | "We exploit a novel setting..." | "We use a new way..." |
| Presenting results | "...yields monthly alphas of over 150 basis points" | "...gives returns of 1.5% per month" |
| Discussing mechanics | "News travels slowly across assets" | "Information moves slowly" |
| Defending results | "Controlling for own-firm momentum..." | "After looking at momentum..." |
| Mechanism | "We conjecture that limited attention leads to..." | "We think that people don't pay attention..." |
| Robustness | "This result is robust to alternative factor models" | "This works with other models too" |
| Pattern | "Returns increase monotonically across deciles" | "Returns go up across groups" |

## Climate Econ Phrases

| Function | Use This | Avoid This |
|----------|----------|-----------|
| Opening hook | "In [year], [country] launched a landmark program..." | "There is a lot of pollution..." |
| Contribution | "To the best of our knowledge, our study provides the first empirical estimate of..." | "No one has studied this before..." |
| Identification | "Exploiting the spatial discontinuity in regulation stringency..." | "Using the difference in rules..." |
| Data | "We build the most comprehensive database yet compiled on..." | "We collected a lot of data..." |
| Results cascade | "The changes triggered a cascade of behavioral changes..." | "People changed what they did..." |
| Mechanism | "The effect was concentrated among individuals aged 60 and above" | "Older people were affected more" |
| Cost-benefit | "A back-of-the-envelope calculation suggests that..." | "We estimate roughly..." |
| Policy | "[Country]'s experience offers an important lesson for other developing countries" | "Other countries should do this too" |

## Identification Phrases

| Function | Use This | Avoid This |
|----------|----------|-----------|
| Stating the problem | "Testing [X] poses a tricky identification challenge" | "It's hard to know if X causes Y" |
| Presenting the shock | "We identify natural experiments that affect [X] through their effect on [Y]" | "We found something random" |
| Exogeneity claim | "Plausibly exogenous" / "Conditionally random variation" | "Totally random" / "Definitely exogenous" |
| Exogeneity test | "Are neither economically nor statistically related to subsequent [outcomes] (p-value = .965)" | "Don't seem to be related to outcomes" |
| Parallel trends | "The identifying assumption... is, as always, parallel trends, which we can evaluate directly" | "We assume trends are the same" |
| Exclusion restriction | "While it is never possible to 'prove' that an instrument satisfies the exclusion restriction..." | "The instrument is definitely valid" |
| Stacked DiD | "Our research design is equivalent to [estimator], which [citation] demonstrate to be unbiased" | "We use a better DiD method" |
| Alternative channel | "We investigate the plausibility of this identifying assumption through the lens of the leading alternative explanation" | "We check if something else is going on" |
| Causal interpretation | "Permit the plausibly causal interpretation that..." | "This proves that..." |

## ECF Phrases

| Function | Use This | Avoid This |
|----------|----------|-----------|
| Introducing a point | "A prominent feature of..." / "A defining feature of..." | "An interesting thing about..." |
| Referring to evidence | "Consistent with this prediction, we find..." | "Like we thought,..." |
| Presenting a result | "As is shown, the coefficient..." | "The number is..." |
| Acknowledging concern | "An important concern is..." / "One might worry that..." | "A problem might be..." |
| Addressing concern | "To account for this possibility..." / "We address this issue by..." | "To fix this..." |
| Emphasizing robustness | "The results are virtually identical if..." | "The results don't change" |
| Qualifying | "That being said," / "Arguably," | "But then again," |
| Explaining | "Intuitively," / "To see this,..." | "Basically," |
| Concluding | "We may thus conclude that..." | "So in the end..." |
| Interpretation | "...statistically highly significant. It is also economically significant. Given that the sample mean is [X], an increase of [Y] implies [Z]%, corresponding to [dollar amount]" | "...significant and big" |

## Anti-Patterns (Never Use in Any Field)

| Never Write | Why | Instead |
|------------|-----|---------|
| "It is important to note that..." | Throat-clearing | Just say it |
| "The literature has long been interested in..." | Empty motivation | Start with the puzzle |
| "To the best of our knowledge, this is the first study to..." | Overclaiming (unless genuinely first) | "We contribute to the literature by providing..." |
| "Interestingly, we find that..." | Let the reader judge interest | "We find that..." |
| "This paper investigates the relationship between X and Y." | Says nothing about findings | State what you FIND, not what you look for |
| "Our results are robust." | Empty claim without specificity | "The coefficient is stable across [specific alternative specifications]" |
| "We perform a regression of Y on X." | Passive, wordy | "We regress Y on X" or "Table 3 reports estimates from regressing Y on X" |
