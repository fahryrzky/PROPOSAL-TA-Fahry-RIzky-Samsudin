# Field Overlap Matrix

Rules for blending styles when a paper spans two subfields.

---

## Overlap Scenarios

| Scenario | Narrative Hook | Results Presentation | Identification Framing | Literature Integration | Conclusion |
|----------|---------------|---------------------|----------------------|----------------------|------------|
| Climate + Identification | Climate style (high-stakes hook) | Climate style (cascade of evidence) | Identification style (meticulous defense) | Climate style (numbered contributions) | Climate style (broad lessons + limitations) |
| EAP + Identification | EAP style (puzzle hook) | EAP style (horse race → alphas) | Identification style (barbell defense) | EAP style (selective synthesis) | EAP style (brief, no new results) |
| ECF + Identification | ECF style (broad observation hook) | ECF style (visual first → progressive regressions) | Identification style (concrete example → threat → fix) | ECF style (integrated, not ghettoized) | ECF style (policy/welfare implications) |
| EAP + ECF | Use the dominant substantive field's hook | EAP for asset-pricing sections; ECF for corporate-finance sections | Follow whichever field is dominant in the section being written | Blend: EAP selectivity + ECF integration | Use dominant field's conclusion style |
| Climate + ECF | Climate style (policy stakes) | Climate style (cascade) with ECF interpretation formula | Climate style (unique setting) with ECF concrete examples | Climate style (numbered contributions) | Climate style (broad lessons) |

## Priority Rules by Paper Element

### Introduction
1. The substantive field's hook style always dominates
2. If the paper's primary contribution is identification, use Identification style for the "This paper" paragraph
3. Contribution framing: use Climate style (numbered, sweeping) for Climate papers; EAP style (mechanism-driven) for EAP papers; ECF style (concise, quantified) for ECF papers

### Empirical Strategy / Identification
1. ALWAYS use Identification style for the defense section if the paper uses quasi-experimental variation
2. The "confident claim" voice should match the substantive field
3. The "meticulous defense" voice follows Identification style regardless of field
4. ECF-style concrete examples (named cities/firms) enhance any identification section

### Results
1. EAP papers: horse race → alphas → alternatives sequence
2. Climate papers: figure first → tables → decomposition → dynamics → cost-benefit
3. ECF papers: visual (bin scatter) → simple regression → progressive controls → robustness subsections
4. All fields: use the ECF interpretation formula (statistical + economic + real-world equivalent)

### Mechanisms / Heterogeneity
1. Climate papers: subgroup decomposition with named channels
2. EAP papers: mechanism tests that rule out alternatives
3. ECF papers: interaction terms and split-sample analyses
4. Cross-field: use the Climate decomposition approach but with ECF-style concrete examples

### Conclusion
1. Climate: broad lessons + limitations + future research + policy implications
2. EAP: brief summary + future research. No new results.
3. ECF: short summary + policy/welfare implications
4. Identification papers follow their substantive field's conclusion style

## Detection of Cross-Field Papers

A paper is classified as cross-field when the top two field scores differ by less than 3 points in the keyword scoring system. Common cross-field patterns:

- **EAP + Identification:** Papers studying return predictability or asset prices using natural experiments (e.g., Kelly & Ljungqvist)
- **Climate + Identification:** Environmental economics papers with strong causal identification strategies (e.g., He et al.)
- **ECF + Identification:** Corporate finance papers exploiting quasi-experimental variation (e.g., Giroud & Mueller)
- **EAP + ECF:** Papers at the intersection of asset pricing and corporate finance (e.g., studying how corporate events affect stock returns)
