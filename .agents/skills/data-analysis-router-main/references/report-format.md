```markdown
## 9. Chart Suggestions
- Chart:

## 10. Missing Data Or Validation Needed
- Missing field/table:

```

## Style Rules

- Put the domain judgment before detailed analysis.
- Explain formulas when metrics could be ambiguous.
- Mark assumptions explicitly.
- Keep recommendations connected to observed findings.
- Say "cannot calculate from current data" when required fields are absent.
