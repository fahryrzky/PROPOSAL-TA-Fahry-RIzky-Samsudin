# 响应选项、量尺、题序与计分

## 1. 先确定回答任务

响应格式服务测量对象。事实、频率、强度、满意度、同意度、可能性、重要性和比较判断具有不同语义，不要因为界面方便统一改成“非常不同意—非常同意”。

## 2. 名义与多选选项

- 单选类别尽量互斥且覆盖合理答案；时间区间和金额区间边界不得重叠。
- “其他”“不知道”“不适用”“拒绝回答”“未作答”含义不同，使用不同代码。
- “以上都不是”和“以上均是”会与随机化、漏选和多选逻辑相互影响，只有必要时使用。
- 多选题说明“可多选”及数量限制；导出时每个选项独立变量，并记录未选与未展示的区别。
- 选项过多时先按分析用途分组；搜索下拉、分页或级联必须经过可用性测试。

## 3. 数值与时间题

明确单位、范围、整数/小数、零的含义和异常值处理。日期采用目标人群熟悉的格式，避免年月日歧义。软校验允许确认极端但真实的值；硬校验只用于逻辑上不可能的值，并提供恢复路径。

## 4. 评定量尺

逐项论证：

- **单极/双极**：从无到高是单极；负到正是双极。中点语义不同。
- **点数**：没有跨情境万能点数；依据构念可区分程度、模式、负担、既有版本与预测试选择。
- **标签**：端点和中间点的词义要与间距假设相符；数字标签不能替代语义说明。
- **中点**：真实中性/中等状态存在时保留；不应用去掉中点强迫表达不存在的立场。
- **不知道/无意见**：与中点、不适用和拒答分开；是否显式提供取决于知识边界、模式和研究目的。
- **方向**：整份问卷尽量一致；若实验性反转顺序，记录随机化变量。

Likert item 是单个有序项目，Likert scale 通常指多个项目的组合。除非计分与测量证据支持，不要把单题当连续尺度，也不要默认等距解释。

## 5. 反向项目与共同方法问题

不要为了“显得严谨”机械加入反向题。否定和反向措辞可能形成方法因子、增加误读。共同方法风险优先通过来源分离、时间分离、题序与心理分隔、中性措辞、保密说明和不同数据源控制；统计补救不能替代设计。

## 6. 矩阵、排序和常数和题

- 矩阵仅用于同一题干、同一量尺和认知任务；移动端优先逐题显示。
- 排序候选项过多会增加负担和随意作答；必要时先筛选再排序。
- 常数和/预算分配要求较高算术负担，只在权衡本身是测量对象且经过测试时使用。
- 滑杆若无离散标签、默认位置或键盘可达性，可能引入不可见偏差；记录初始状态并测试设备差异。

## 7. 问卷流程

推荐结构：知情同意与必要筛选 → 易答且切题的暖场 → 核心事实/行为 → 核心态度/量表 → 敏感题 → 必需人口学资料 → 收尾与联系方式分离。

分块应保持对话逻辑，同时控制上下文效应。每页题数、进度条、返回修改、强制作答和自动保存都需结合风险测试。人口学题不是默认必问；只收集抽样、异质性分析、等值性或必要描述所需信息。

## 8. 计分

- 只有理论、原工具或验证证据支持时计算总分/分量表。
- 写明反向计分、允许缺失数、缺失处理、加权、转换、范围和版本。
- 新题组在正式验证前只给“拟议计分”，不得称已建立量表。
- 形成型指数的权重需理论、政策或模型依据，不能用内部一致性筛项。
- 阈值、风险分层和诊断界点必须来自适用人群与用途的外部证据；无证据时不设。
